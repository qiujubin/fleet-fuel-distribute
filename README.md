# 车队每日加油数据分发系统

> 最后更新：2026-09-28 ｜ 维护：WorkBuddy

把每天从系统导出的加油名单，自动分发到 49 辆车（+15 个尿素文件）的油耗计算模板，再一路汇总到油耗考核表与油耗分析汇总。
原来全手工逐车复制粘贴，现在一次运行 **10~30 秒**。

## 1. 数据链路

```
数据/车辆加油_管理(日期).xlsx          ← 每天从系统导出的原始名单
        │ ① 按系统编号去重、分流
        ▼
车辆油耗计算模板/                      ← 共 64 个文件（油车 49 + 尿素 15）
  ├─ 编号-车型-车牌.xlsx               ← 油车文件（挂车/9.6米/7.6米/4.2米）

  │    └─ [计算模板]  填 G=登记时间；有效"是"行再填 F 并生成累计公式
  └─ 尿素xx-车牌.xlsx                  ← 尿素文件（15 辆车）
        │ ② "是"行（有效加满）写入
        ▼
油耗考核10月_宏.xlsm

        │ ③ 4 张油耗 sheet（干线/华北/华东/华南，每车一行公式）自动取数
```

## 3. 日常怎么用

**你要做的**：把当天导出的 `车辆加油_管理(日期).xlsx` 放进「数据」文件夹，然后说一句「跑今天的加油名单」。

**前置检查**：跑之前把 WPS / Excel 里开着的**考核表**和**车辆模板**关掉，否则要么写入失败，要么你保存时会覆盖程序的结果。

**一键入口（推荐）**：`python run_daily.py` —— 内部自动串起三段：主链路（分发→考核→每日加油记录→透视表→宏同步）→ 回溯修正检测 → 必要时二次同步。不用再手工分步跑。
**程序会做**：分发 → 写考核 → 刷每日加油记录 → 刷新透视表 → 调宏同步汇总 → 回溯检查 → 出报告。

**你要看的**：报告分节——新增明细、有效"是"行、排除词记录、数据质量提醒（异常只在报告里说，从不写进文件）。发现异常去系统里核对原始数据。

## 5. 业务规则速查

**分发路由**
- 类型含「尿素」→ 尿素文件；`单价 < 5 元`（尿素价）但类型写「加油」→ 也进尿素文件并提醒
- 备注含 `发动机 / 发电机 / 小油箱 / 新车` → 只进「加油数据」，不进「计算模板」，列入报告待复核
- 备注同时含"加油"和"尿素" → 跳过，留人工处理

**有效"是"规则（油耗周期的核心）**
- 同一天同一辆车多次加满 → **只有当天最后一个"是"有效**，前面的按"否"处理
- 有效"是"行：`时间A` = 上一个有效"是"的时间B；金额/升数 = 自上一个有效"是"之后所有行的累计
- 跨天补录会出现"回溯"：新记录到货后，昨天生效的那条要降级、新记录升为有效 → 用 `retro_fix.py`

**骨架维护**：每消耗一行公式骨架，立刻在底部补一行（连数字格式一起），余量恒定 15 行

**「每日加油记录」**（宏的输入快照）
- 源 = 最新导出里登记日期为 **n-1** 的记录
- 排除尿素 / 错标尿素（单价 < 5）
- 排除词记录**独立占一行**，"是"改"否"，不参与同日压缩
- 其余同车同日：有"是"留最后一个"是"，全"否"留最后一个

**周期**：汇总同步是 **T+1**——今天加的油，明天才进「每日加油记录」→ 透视表 → 4 张 sheet → 汇总

## 6. 出问题怎么办

| 现象 | 可能原因 / 处理 |
|---|---|
| 提示文件被占用 | WPS/Excel 开着考核表或车辆文件 → 关掉重跑（**重跑是幂等的，只补缺的，不会写重**） |
| 报告里有"数据质量提醒" | 系统里的原始数据有问题（金额≠油量×单价、里程倒退、单价异常），去系统核对 |
| 汇总里没看到最新数据 | 正常（T+1），当天的油次日进；如果超过一天还没进，看报告里的透视表/宏日志 |
| 宏不见了 / 按钮消失 | 已由 COM 架构根治；若仍出现，检查是否用 openpyxl 动过考核表 |
| 想撤销某次改动 | `backup_daily\` 是处理前快照；各类一次性修复前的快照见根目录 `kaohe_before_*.xlsm` |
| 导出文件被误删记录 | 用 `restore_export_rows.py` 从车辆模板反查恢复 |
