## 写入铁律
- 绝对禁止 openpyxl 保存任何 xlsx/xlsm；写入只用 WPS COM（Ket.Application），只读用 calamine
- COM 写时间一律用 `Value2` 存 Excel 序列数，不要写 naive datetime（会被时区转成 GMT）
- `Workbooks.Open` 第三参数是 ReadOnly：写模式必须传 False，写后必须只读回读复核

## 每日流程
`run_daily.py`：⓪ 取数 → ① 分发/写考核/透视表/宏同步 → ② 回溯修正 → ③ 二次同步（有修正时）→ ④ 打冷同步 → ⑤ 4 张油耗页面清零+大排序 → ⑥ 备份清理（保留 3 天）

## 常见源系统录入错误（每次跑完要留意）
- 单价漏打/错位：3.31→8.31、5.64→8.64、60→8.60（用「金额÷油量」反算验证）
- 同一笔被两人重复登记（核对金额+油量+里程+加油站是否完全相同）
- 油量小数点右移（6433→64.33）
- 类型填"油卡加油"但单价 2.x（实为尿素）
