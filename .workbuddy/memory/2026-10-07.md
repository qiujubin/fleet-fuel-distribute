# 补充调查：用户问「为什么只有干线有未加满记录」

用户观察：「每日加油记录」里未加满（否）的记录只有干线，华北/华东/华南都没有。

**排查结论：不是 bug，是规则 + 数据分布的自然结果。**

「每日加油记录」由 `refuel_sheet.compute_rows` 生成，规则（源码 docstring）：
```
排除尿素/错标尿素(单价<5)；
排除词记录(发动机/发电机/小油箱/新车)保留但"是"改"否"，独立占一行；
其余同车牌同日：有"是"留最后一个"是"，全"否"留最后一个"否"
```
→ **每车每天只留一条**；"否"只在**该车当天完全没加满过**时才会出现。

**数据佐证**（用 `compute_rows(run_date=...)` 模拟）：
- `run_date=10-06`(n-1=10-05)：15 条，3 条"否"，全是干线（粤BNV030 / 京AEP303 / 粤BQN066）
- `run_date=10-07`(n-1=10-06)：12 条，4 条"否"，全是干线（粤BQN066 / 粤BNV030 / 京AEP303 / 粤ACJ995）
- 其他区域的车**当天都有"是"**，所以它们的记录以**"是"的形式**正常出现在「每日加油记录」里
  （10-07：华东 3 条 = 粤BT802F/粤BY2J27/京LPW138，华南 1 条 = 粤B17K86），当天的"否"被同日的"是"顶掉
- 原始导出里其他区域**确实有**"否"记录（华东 粤BY2J27/粤BT802F、华南 粤B17K86/粤BH91Z8 都出现过），只是那几天他们不是"全否"

**不是回归**：`git log --follow -- refuel_sheet.py` 只有初始提交 `cd59d19`，这条规则从未改过。

**根因是分布**：干线 20 台（车最多），且干线车跑长途常"不满就加" → "当天全否"的车几乎都在干线；
华北仅 2 台、华东 6 台，基数小，出现"全否"的概率低。

**待用户确认需求**：是否希望「每日加油记录」**额外保留**当天"既有是又有否"里的那些"否"记录（现在被丢弃）。
若要改 `refuel_sheet.py`，需同步评估对宏「同步油耗到汇总」的影响（宏以该 sheet 为输入）。
