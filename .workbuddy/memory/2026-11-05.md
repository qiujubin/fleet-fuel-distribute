## 🔍 查清「干线油耗只有 2 个」的原因（15:00 前后）
### 区域表的取数链路（重要）
`干线/华北/华东/华南油耗` 的「加油时间(A)(B)」是公式：
```
=IF(XLOOKUP(B7,每日加油记录!B:B,每日加油记录!I:I,"当日未加油",0,-1)="否",
    "油卡余额不足未加满油",
    XLOOKUP(B7,每日油耗!D:D,每日油耗!E:E,"当日未加油"))
```
- 第一层查 `每日加油记录`（当天 n-1 的原始登记）→ 判断是否加满
- **第二层查 `每日油耗`（透视表）→ 取时间**；取不到就显示"当日未加油"
- **所以区域表能显示几行，取决于透视表里有几行**

### 为什么透视表只有 2 行
- 透视表按「是否加满=是 + 日期」筛选，数据源范围只覆盖到第 **3705** 行
- 我补的 6 条在 **3706-3711**（追加在末尾），超出数据源范围 → 透视表里没有 → 区域表显示"当日未加油"
- 汇总本身不受影响（8 条都在，因为汇总是直接写的）

### ⚠️ 踩的坑
- 试图把 `PivotCache.SourceData` 改成 `$A$1:$V$3711` → **WPS 直接重建透视表，筛选和布局全丢**（变成显示全部 3652 条历史）

- 结论：**WPS 里不要从 COM 改透视表数据源**；补录行必须"插到数据源范围内"，不能追加到末尾
