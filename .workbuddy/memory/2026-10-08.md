## ✅ 回答用户昨天的疑问：「为什么只有干线有未加满记录」

**结论：不是 bug，规则 + 数据分布所致，且今天的数据直接推翻了「只有干线有」。**

看今天（n-1=**10-07**）的「每日加油记录」17 条，**其他区域确实有"否"记录**：
```
粤BT802F  华东  否  ¥510.01
粤BH91Z8  华南  否  ¥587.33（备注：未加满，只加卡内余额）
京AEP303  干线  否   粤BPV550 干线 否   粤BNJ052 干线 否
粤BQN066  干线  否   粤BES008 干线 否   粤BFM072 干线 否   粤BNT993 干线 否×2
```
**10-06 那天没有**其他区域的"否"，纯粹因为那天华东 3 台、华南 1 台**都只加了一次且都加满**。

规则（`refuel_sheet.compute_rows`，源码写死、git 历史从未改过）：
```
同车牌同日：有"是"留最后一个"是"；全"否"留最后一个"否"
```
→ 每车每天**只留一条**；"否"只在"该车当天完全没加满过"时出现。
干线 20 台（车最多）且跑长途常"不满就加"，所以"全否"的车大概率落在干线 —— 看着像区域筛选，其实是概率。
